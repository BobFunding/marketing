# 동네 GEO — 소상공인 AI 검색 인용 준비도 진단

지역 미용실·네일샵·필라테스·학원의 공개 정보를 점검하는 수동 진단 웹앱입니다. AI 노출이나 순위를 보장하지 않으며 실제 검색을 자동 수행하지 않습니다.

## 클라우드 실행

Node.js 22 이상. 외부 패키지, API 키, 데이터베이스 없이 실행합니다.

```sh
cd /workspace/marketing
npm ci
npm test
npm start
```

서버는 `0.0.0.0:3000`에서 실행합니다. `PORT` 환경변수로 포트를 변경할 수 있습니다. 클라우드 호스팅에서는 제공하는 포트 연결/배포 기능을 사용하세요. GitHub 저장소 링크 자체는 실행 중인 웹사이트 주소가 아닙니다.

## 사용 방법

1. 상호·지역·업종, 진단 날짜, 검색 서비스와 위치·조건을 입력합니다.
2. 홈페이지·지도·플랫폼의 정보를 직접 비교하고 확인한 항목을 체크합니다.
3. 고객 질문 6개를 같은 조건에서 검색하고 관찰 답변·출처 URL·비교 업체를 기록합니다.
4. 개선 우선순위를 입력해 보고서를 만들고 인쇄 또는 PDF로 저장합니다.
5. 필요하면 브라우저에 저장합니다. 데이터는 서버로 전송되지 않으며 다른 기기와 동기화되지 않습니다. 공용 기기에서는 저장 내용을 삭제하세요.

## 검증

`npm test`는 실제 HTTP 서버로 화면·정적 파일 응답과 비공개 경로 차단을 검사합니다. 브라우저 입력·로컬 저장·PDF 출력은 수동으로 확인할 수 있습니다.

## 범위

무료 진단 → 상세 진단 15만 원 → 월 관리 40만 원의 서비스 구성을 예시로 제시합니다. 결제·고객 접수·회원 기능은 포함하지 않습니다. 외부 AI API 연동이나 개인정보 수집 없이 첫 진단 사례를 작성할 수 있습니다.
